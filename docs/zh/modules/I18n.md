# 国际化

**I18n** 模块允许对编辑器用户界面 (Editor UI) 中的字符串进行国际化和更新。

::: warning
本指南适用于 GrapesJS v0.15.9 或更高版本

该模块是最近添加的，因此我们乐于接受在[翻译其他语言的字符串](#adding-new-language)方面的支持。非常感谢您的帮助！
:::

[[toc]]

## 配置

默认情况下，编辑器仅包含英语，如果您需要其他语言，则必须手动导入它们。
**注意**：语言代码在 [ISO 639-1] 标准中定义。

```js
import grapesjs from 'grapesjs';
import it from 'grapesjs/locale/it';
import tr from 'grapesjs/locale/tr';

const editor = grapesjs.init({
  ...
  i18n: {
    // locale: 'en', // 默认区域设置 (locale)
    // detectLocale: true, // 默认情况下，编辑器将检测语言
    // localeFallback: 'en', // 默认回退语言
    messages: { it, tr },
  }
});
```

现在，对于默认语言为意大利语的浏览器，编辑器将被翻译成意大利语（默认情况下 `detectLocale` 选项是启用的）。

## 更新字符串

如果您需要更改某些默认语言字符串，可以使用 [I18n API](/api/i18n.html) 轻松更新它们。
要找到字符串的正确路径，您可以查看 [`en` 区域设置文件] 并在区域设置 (locale) 对象内遵循其内部路径。

假设我们要更新未选择任何元素时样式管理器 (Style Manager) 中空状态的默认消息。

<img :src="$withBase('/sm-empty-state.jpg')">

从 `en` 区域设置文件中，您可以按照以下路径查看它：

```js
{
    ...
    styleManager: {
        empty: 'Select an element before using Style Manager',
        ...
    },
    ...
}
```

所以现在要更新它，您需要这样做：

```js
editor.I18n.addMessages({
  en: {
    // 指示要更新的区域设置 (locale)
    styleManager: {
      empty: 'New empty state message',
    },
  },
});
```

即使 UI 正确显示了更新后的消息，我们强烈建议将所有 API 调用封装在一个[插件](Plugins.html)中。

```js
const myPlugin = editor => {
    editor.I18n.addMessages({ ... });
    // ...
}

grapesjs.init({
  // ...
  plugins: [myPlugin],
});
```

### 生成的字符串

并非所有字符串都在 `en` 本地文件中指明，因为其中一些字符串可以从 `id`、`name` 等生成。
如果您回顾 `en` 文件中的 `styleManager` 路径，您会注意到空的 `properties` 键 (key)：

```js
...
styleManager: {
    ...
    properties: {
        // float: 'Float',
    },
    ...
},
...
```

此对象用于翻译样式管理器 (StyleManager) 内的属性 (property) 名称，因此，例如，如果您需要更改 `margin` 属性的自动生成名称：

<img :src="$withBase('/margin-strings.jpg')">

您需要这样做：

```js
editor.I18n.addMessages({
  en: {
    styleManager: {
      properties: {
        // 键是属性名称（或 id）
        'margin-top': 'Top',
        'margin-right': 'Right',
        'margin-left': 'Left',
        'margin-bottom': 'Bottom',
      },
    },
  },
});
```

## 添加新语言

如果您想通过向我们的仓库 (repository) 添加新语言来支持 GrapesJS，您只需执行以下步骤：

1. 首先，请务必检查 [`src/i18n/locale`](https://github.com/GrapesJS/grapesjs/blob/master/src/i18n/locale) 目录中的语言文件是否已存在。
1. [提交一个新的问题 (issue)](https://github.com/GrapesJS/grapesjs/issues/new?title=XX%20Language%20support) 以避免与其他贡献者发生冲突。为确保起见，还请检查是否没有其他人已经为同一语言提交了问题。
1. 从 `dev` 分支创建一个新分支。
1. 复制（在同一文件夹中）并将 [`en` 区域设置文件] 重命名为您选择的语言名称（请确保符合 [ISO 639-1] 标准）。
1. 现在您可以开始翻译字符串了。
1. 通过查看注释，您可能会注意到某些键 (key) 没有指明（例如 `styleManager.properties`），您可以参考其他区域设置文件。
1. 完成后，您可以从您的分支向 `dev` 分支在 GitHub 上创建一个新的拉取请求 (Pull Request)，并在其中引用您的问题，以便在合并后自动关闭它（您的 PR 消息应包含 `Closes #1234`，其中 1234 是问题 ID）。

## 插件开发

::: warning
本节**仅**适用于插件开发者，如果您使用 [grapesjs-cli](https://github.com/GrapesJS/cli) 初始化您的插件项目，则可以跳过此节。
:::

如果您正在为 GrapesJS 开发插件，并且需要支持某些字符串本地化或只是更改默认字符串，我们建议采用以下结构。

```
plugin-dir
- package.json
- README.md
- ...
- src
    - index.js
    - locale // 在您的 src 目录中创建 locale 文件夹
        - en.js // 所有默认字符串都应放在此处
```

对于您插件特有的字符串，请将它们放在插件名称键 (key) 下：

```js
// src/locale/en.js
export default {
  'grapesjs-plugin-name': {
    yourKey: 'Your value',
  },
};
```

在您的 `index.js` 中使用 `en.js` 文件并添加 `i18n` 选项以允许导入其他本地文件：

```js
// src/index.js
import en from 'locale/en';

export default (editor, opts = {}) => {
  const options = {
    i18n: {},
    // ...
    ...opts,
  };

  // ...

  editor.I18n.addMessages({
    en,
    ...options.i18n,
  });
};
```

下一步是将您的区域设置文件编译到 `<rootDir>/locale` 目录中，以便您的用户可以轻松访问它们。此文件夹可以在您的 git 仓库中被忽略，但应部署到 npm 仓库 (npm registry)。

::: warning
请记住，您可以跳过所有这些冗长的步骤，并使用 [grapesjs-cli](https://github.com/GrapesJS/cli) 初始化您的项目。这将为您创建所有必要的文件夹/文件/命令（在 `init` 命令期间，此步骤默认标记为 `true`，即使您的项目中不需要 i18n，我们也建议保留它）。
:::

最后，您的插件用户将能够通过这种方式导入其他区域设置文件（如果存在）：

```js
import grapesjs from 'grapesjs';

// 从您的插件导入
import yourPlugin from 'grapesjs-your-plugin';
import ch from 'grapesjs-your-plugin/locale/ch';
import fr from 'grapesjs-your-plugin/locale/fr';

const editor = grapesjs.init({
  ...
  plugins: [ yourPlugin ],
  pluginsOpts: {
      [yourPlugin]: {
          i18n: { ch, fr }
      }
  }
});
```

[ISO 639-1]: https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes
[`en` 区域设置文件]: https://github.com/GrapesJS/grapesjs/blob/master/src/i18n/locale/en.js
